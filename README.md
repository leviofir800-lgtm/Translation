# מתרגם חי: עברית ↔ תאית

אפליקציית אינטרנט לשיחה חיה בין בעל עסק שמדבר עברית לבין העובדים התאילנדים שלו. היא מקשיבה לדיבור ומציגה את התרגום באותיות גדולות אחרי כל משפט. אפשר גם לתרגם לאנגלית ומאנגלית.

## מה האפליקציה עושה
- **תרגום של משפטים שלמים**: האפליקציה מחכה שהדובר יעצור (בערך שנייה) ורק אז מתרגמת את כל המשפט, כדי שהתרגום יבין את ההקשר.
- **מסך נקי**: מופיעים רק המשפטים הסופיים. בזמן שמדברים רואים רק ● ● ●.
- **שני טלפונים**: כל אחד מדבר לטלפון שלו בשפה שלו, ורואה את מה שהשני אמר בשפה שלו.
- **תרגום חכם עם Claude**: מבין את ההקשר של השיחה ומשתמש במילון אישי של מילים ושמות מהעבודה.
- **השמעה**: אפשר להקריא כל תרגום בקול, ולחיצה על משפט משמיעה אותו שוב.

## איך משתמשים
1. פותחים את הקישור ב-**Google Chrome** (אנדרואיד) או ב-**Safari** (אייפון).
2. בוחרים באיזו שפה מדברים לטלפון (🎤 עברית / 🎤 ไทย / 🎤 English) ולאיזו שפה לתרגם.
3. לוחצים על **🎤 Start**, מאשרים גישה למיקרופון ומדברים.

כפתורים:
- **A− / A+**: מקטינים או מגדילים את הטקסט.
- **🔈**: מקריא את התרגום בקול (אפשר לחבר אוזנייה). בזמן ההקראה הטלפון לא מקשיב, כדי שלא יתרגם את עצמו.
- **לחיצה על משפט**: משמיעה אותו שוב.
- **🔗**: חיבור לטלפון נוסף.
- **⚙️ / ✨**: הגדרות התרגום החכם.
- **🗑**: מנקה את המסך.

## חיבור שני טלפונים
1. בטלפון של אבא (עברית → תאית) לוחצים 🔗 ואז **"צור חיבור"**.
2. בטלפון של העובד סורקים את ה-QR, או לוחצים **"שלח קישור"** ושולחים לו בוואטסאפ. הקישור פותח אצלו את האפליקציה כבר מחוברת ובתאית.
3. בשני הטלפונים לוחצים **Start**.

החיבור נשמר, גם אם סוגרים ופותחים את האפליקציה. כדי להתנתק לוחצים 🔗 ואז **"נתק"**.
ההודעות בין הטלפונים מוצפנות עם קוד החיבור, כך שרק שני הטלפונים יכולים לקרוא אותן.

המסך נשאר דולק כל עוד ההאזנה פועלת. גם אם הדפדפן עוצר את ההאזנה אחרי שקט, היא ממשיכה לבד.

## תרגום חכם (Claude)
המפתח של Claude לא נמצא בקוד (האתר ציבורי). הוא שמור בשרת קטן וחינמי ב-Cloudflare (`worker.js`), והאפליקציה פונה אליו עם **קוד גישה** שמגיע בקישור.

**הקמה (פעם אחת):**
1. ב-https://console.anthropic.com: **Set up billing**, תקרת הוצאה חודשית, ואז **Create key**.
2. ב-https://dash.cloudflare.com (חשבון חינמי): **Workers & Pages → Create → Import a repository → Connect GitHub**, בוחרים את המאגר `Translation`, משאירים את השם `translator` ולוחצים **Deploy**. Cloudflare בונה את השרת מ-`worker.js` לפי `wrangler.jsonc`, ומעדכן אותו לבד בכל שינוי במאגר.
3. בעמוד של ה-Worker: **Settings → Variables and Secrets → Add**, פעמיים, מסוג **Secret**:
   - `ANTHROPIC_API_KEY` = המפתח של Claude
   - `APP_CODE` = קוד גישה שבוחרים (סיסמה ארוכה)
4. את כתובת השרת מכניסים ל-`AI_PROXY` ב-`index.html` (כרגע: `https://translator.leviofir800.workers.dev/`).

**שימוש:** שולחים לאנשים את הקישור `https://leviofir800-lgtm.github.io/Translation/#code=<קוד הגישה>`. אחרי פתיחה אחת הקוד נשמר בטלפון, והכפתור ⚙️ הופך ל-✨. הקישור של "חיבור שני טלפונים" כולל את הקוד אוטומטית, ובהגדרות יש כפתור **"שלח קישור לאפליקציה"**.

- מי שאין לו את הקוד מקבל תרגום רגיל של Google ולא יכול להשתמש בחשבון שלך.
- אם הקוד דלף, מחליפים את `APP_CODE` ב-Cloudflare ושולחים קישור חדש.
- **על השיחה**: כמה מילים על מי מדבר ואיפה, למשל "בעל עסק מדבר עם העובדים התאילנדים שלו בחממות". כך Claude בוחר את המילים והטון המתאימים.
- **מילון אישי**: שורה לכל מילה, למשל `יעקב = ยาอากอป`. Claude ישתמש תמיד במילים האלה.
- **מודל**: Opus 5 (הכי מדויק, ברירת המחדל), Sonnet 5 (מהיר וזול יותר), Haiku 4.5 (הכי מהיר וזול).
- אם אין אינטרנט, הקוד לא תקין או שנגמרה היתרה, האפליקציה ממשיכה לתרגם עם Google והכפתור הופך ל-⚠️.
- אפשר גם להדביק בהגדרות מפתח API אישי במקום קוד גישה. המפתח נשמר רק באותו טלפון.

## בדיקת איכות התרגום
פותחים `https://leviofir800-lgtm.github.io/Translation/#test` בטלפון שבו התרגום החכם פעיל (✨), ולוחצים **הרץ**. האפליקציה מתרגמת כ-36 משפטי עבודה (`tests.js`) בשני הכיוונים, וגם דרך אנגלית לצורך השוואה, ומציגה כמה זמן לקח כל משפט. **העתק תוצאות** מעתיק את הכול כדי לשלוח לבדיקה.
