# מתרגם חי: עברית → אנגלית

אפליקציית אינטרנט פשוטה: היא מקשיבה לדיבור בעברית ומציגה מיד תרגום לאנגלית באותיות גדולות, כדי שהמטפלת תבין מה אומרים לידה.

## מה חדש
- **תרגום של משפטים שלמים**: האפליקציה מחכה שהדובר יעצור (בערך שנייה) ורק אז מתרגמת את כל המשפט. כך התרגום מבין את ההקשר ולא מתרגם מילה-מילה.
- **מסך נקי**: מופיעים רק המשפטים הסופיים. בזמן שמדברים רואים רק ● ● ●.
- **חיבור בין שני טלפונים**: כל טלפון מקשיב לשפה שלו. מה שנאמר בעברית מופיע בטלפון השני באנגלית, ומה שנאמר באנגלית מופיע בטלפון הראשון בעברית.
- **תמיכה בתאית**: בוחרים באיזו שפה מדברים לטלפון (עברית, English או ไทย) ולאיזו שפה לתרגם.
- **התאמת שפות אוטומטית**: כששני טלפונים מתחברים, כל טלפון מתרגם אוטומטית לשפה של הטלפון השני.
- **השמעה חוזרת**: לחיצה על משפט משמיעה אותו שוב, גם כשההקראה בקול כבויה.
- **תרגום חכם עם Claude**: עם מפתח API של Claude, התרגום מבין את ההקשר של השיחה ומשתמש במילון אישי שלכם.

## איך משתמשים
1. פותחים את `index.html` ב-**Google Chrome** (אנדרואיד/מחשב) או ב-**Safari** (אייפון).
2. לוחצים על **🎤 Start** ומאשרים גישה למיקרופון.
3. מניחים את הטלפון או הטאבלט ליד המטפלת. כל מה שנאמר בעברית מופיע מיד באנגלית.

כפתורים:
- **A− / A+**: מקטינים או מגדילים את הטקסט.
- **🔈**: מקריא את התרגום בקול (אפשר לחבר אוזנייה). בזמן ההקראה הטלפון לא מקשיב, כדי שלא יתרגם את עצמו.
- **🎤 עברית / 🎤 English / 🎤 ไทย**: באיזו שפה מדברים לטלפון הזה, ולידו לאיזו שפה לתרגם. כשמחוברים לטלפון נוסף, שפת התרגום נקבעת לבד לפי השפה של הטלפון השני.
- **לחיצה על משפט**: משמיעה אותו שוב.
- **🔗**: חיבור לטלפון נוסף.
- **🗑**: מנקה את המסך.

## חיבור שני טלפונים
1. בטלפון הראשון (עברית) לוחצים 🔗 ואז **"צור חיבור"**.
2. בטלפון של המטפלת סורקים את ה-QR, או לוחצים **"שלח קישור"** ושולחים לה בוואטסאפ. הקישור פותח אצלה את האפליקציה כבר מחוברת ובאנגלית.
3. בשני הטלפונים לוחצים **Start**.

החיבור נשמר, גם אם סוגרים ופותחים את האפליקציה. כדי להתנתק לוחצים 🔗 ואז **"נתק"**.
ההודעות בין הטלפונים מוצפנות עם קוד החיבור, כך שרק שני הטלפונים יכולים לקרוא אותן.

המסך נשאר דולק כל עוד ההאזנה פועלת. גם אם הדפדפן עוצר את ההאזנה אחרי שקט, היא ממשיכה לבד.

## תרגום חכם (Claude)
המפתח של Claude לא נמצא בקוד (האתר ציבורי). הוא שמור בשרת קטן וחינמי ב-Cloudflare (`worker.js`), והאפליקציה פונה אליו עם **קוד גישה** שמגיע בקישור.

**הקמה (פעם אחת):**
1. ב-https://console.anthropic.com: **Set up billing**, תקרת הוצאה חודשית, ואז **Create key**.
2. ב-https://dash.cloudflare.com (חשבון חינמי): **Workers & Pages → Create → Start with Hello World**, שם `translator`, **Deploy**.
3. **Edit code**: מוחקים הכול, מדביקים את התוכן של https://leviofir800-lgtm.github.io/Translation/worker.js ולוחצים **Deploy**.
4. **Settings → Variables and Secrets → Add**, פעמיים, מסוג **Secret**:
   - `ANTHROPIC_API_KEY` = המפתח של Claude
   - `APP_CODE` = קוד גישה שבוחרים (סיסמה ארוכה)
5. את כתובת השרת (`https://translator.<השם-שלך>.workers.dev`) מכניסים ל-`AI_PROXY` ב-`index.html`.

**שימוש:** שולחים לאנשים את הקישור `https://leviofir800-lgtm.github.io/Translation/#code=<קוד הגישה>`. אחרי פתיחה אחת הקוד נשמר בטלפון, והכפתור ⚙️ הופך ל-✨. הקישור של "חיבור שני טלפונים" כולל את הקוד אוטומטית, ובהגדרות יש כפתור **"שלח קישור לאפליקציה"**.

- מי שאין לו את הקוד מקבל תרגום רגיל של Google ולא יכול להשתמש בחשבון שלך.
- אם הקוד דלף, מחליפים את `APP_CODE` ב-Cloudflare ושולחים קישור חדש.
- **על השיחה**: כמה מילים על מי מדבר ואיפה, למשל "בעל עסק מדבר עם העובדים התאילנדים שלו בחממות". כך Claude בוחר את המילים והטון המתאימים.
- **מילון אישי**: שורה לכל מילה, למשל `יעקב = ยาอากอป`. Claude ישתמש תמיד במילים האלה.
- **מודל**: Opus 5 (הכי מדויק, ברירת המחדל), Sonnet 5 (מהיר וזול יותר), Haiku 4.5 (הכי מהיר וזול).
- אם אין אינטרנט, הקוד לא תקין או שנגמרה היתרה, האפליקציה ממשיכה לתרגם עם Google והכפתור הופך ל-⚠️.
- אפשר גם להדביק בהגדרות מפתח API אישי במקום קוד גישה. המפתח נשמר רק באותו טלפון.
