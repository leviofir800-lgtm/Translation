# מתרגם חי: עברית → אנגלית

אפליקציית אינטרנט פשוטה: היא מקשיבה לדיבור בעברית ומציגה מיד תרגום לאנגלית באותיות גדולות, כדי שהמטפלת תבין מה אומרים לידה.

## איך משתמשים
1. פותחים את `index.html` ב-**Google Chrome** (אנדרואיד/מחשב) או ב-**Safari** (אייפון).
2. לוחצים על **🎤 Start** ומאשרים גישה למיקרופון.
3. מניחים את הטלפון או הטאבלט ליד המטפלת. כל מה שנאמר בעברית מופיע מיד באנגלית.

כפתורים:
- **A− / A+**: מקטינים או מגדילים את הטקסט.
- **🔈 Speak**: מקריא את התרגום באנגלית בקול (אפשר לחבר אוזנייה).
- **Clear**: מנקה את המסך.

המסך נשאר דולק כל עוד ההאזנה פועלת. גם אם הדפדפן עוצר את ההאזנה אחרי שקט, היא ממשיכה לבד.

## איך מעלים לאינטרנט (בחינם, עם קישור קבוע)
הדפדפן מאפשר גישה למיקרופון רק בכתובת `https`. לכן הכי פשוט להשתמש ב-GitHub Pages:
1. ממזגים את הענף ל-`main`.
2. ב-GitHub: **Settings → Pages → Deploy from a branch → main / (root)** → Save.
3. אחרי כדקה האפליקציה זמינה בכתובת `https://leviofir800-lgtm.github.io/Translation/`.
4. בטלפון פותחים את הקישור ובוחרים **"הוספה למסך הבית"**. כך האפליקציה נפתחת כמו כל אפליקציה אחרת.

## הערות
- צריך חיבור לאינטרנט, גם לזיהוי הדיבור וגם לתרגום.
- אם כמה אנשים מדברים ביחד, הזיהוי יהיה פחות מדויק. הכי טוב כשהמכשיר קרוב לדובר.
